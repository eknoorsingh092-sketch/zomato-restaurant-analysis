# 🍽️ Zomato Restaurant Analysis

## Overview
Exploratory Data Analysis and Machine Learning on 
7,000+ Zomato Bangalore restaurants to understand 
what drives restaurant success and predict ratings.

## Business Questions Answered
1. Which restaurant type is most common?
2. What is the distribution of restaurant ratings?
3. Does online ordering affect ratings?
4. Does table booking affect ratings?
5. Which areas have the most restaurants?
6. What is the most common cost range?
7. Which cuisine type is most popular?
8. Can we predict restaurant ratings using ML?

## Key Findings
- Quick Bites dominates with 2,840 restaurants
- Most restaurants rated between 3.5 and 4.0
- Table booking restaurants rate 0.59 higher
- Online ordering slightly improves ratings
- North Indian cuisine leads with 1,943 restaurants
- Most restaurants priced between ₹200-₹600
- Number of ratings is the most important ML feature

## Machine Learning
- **Model:** Random Forest Regressor
- **R2 Score:** 0.38
- **MAE:** 0.24
- **RMSE:** 0.36
